# Native Character live validation — 2026-09-17

Validated against the authenticated Google Flow UI using a disposable project. No cookies, CAPTCHA tokens, signed URLs, image bytes, or live UUIDs are retained here.

## Operations

1. **Create project**
   - Created a new Google Flow project through the UI.
   - Project identifier is redacted as `<PROJECT_UUID>`.
   - Code comparison: the validation project is supplied as `project_id` to every native RPC builder and is not generated by local FlowKit CRUD.

2. **Create native Character through API / C4BZMd**
   - Called `POST /api/characters/native` with the disposable project and name `Prompt Character Validation`.
   - HTTP 200 returned normalized `project_id` and `character_id` fields.
   - Code: `agent/api/characters.py:create_native` → `FlowClient.create_native_character` → `flow_batch.native_character_create_request`.
   - Wire shape: `[[project_uuid, null, null, [1, name, []]]]`.

3. **Bind portrait upload / maseQ**
   - Called `POST /api/flow/native-character-portrait` with `ui.png` and the Character UUID returned by C4BZMd.
   - HTTP 200 returned normalized fields: `media_id`, `project_id`, `workflow_id`, `character_id`, `status`.
   - Status observed: `CAE`.
   - Code: `agent/api/flow.py:native_character_portrait` → `FlowClient.bind_native_portrait` → `flow_batch.native_portrait_request` and `read_native_portrait_binding`.
   - Response fixture and request fixture: `docs/google-flow-native-character-maseq-capture-2026-09-17.md`.

4. **Attach catalog voice to uploaded-portrait Character**
   - API attempt with `voice_id=achird` returned HTTP 502 and Google error `[3]`.
   - The same Character was then opened in the Google Flow UI; selecting `Achird` and clicking `Add to character` succeeded. UI state showed `voice_selection` / `achird`.
   - Code comparison: `flow_batch.native_catalog_voice_request` matches the approved `rzMKMb` shape and field mask `entity_info.character_info.audio_references`, but the API path has not been proven successful by Google.

5. **Create Character from prompt**
   - In the Google Flow UI, opened `Create character`, selected `The Familiar`, entered a prompt describing a calm Vietnamese mechanic, and clicked `Start generation`.
   - Flow navigated to a new Character editor route with the generated Character. The displayed name was `Untitled character`.
   - This is a distinct prompt-generated Character from the upload-bound Character.

6. **Attach catalog voice to prompt-generated Character**
   - In the prompt-generated Character editor, selected `Achird` and clicked `Add to character` once.
   - UI state showed `voice_selection` / `achird`.

with a fresh C4BZMd Character and `model: "NARWHAL"`. The endpoint returned
normalized `project_id`, `character_id`, `media_id`, and `workflow_id`; the

The API returned the requested project, Character, and voice IDs. Reloading
that Character editor showed the voice control as `achird`, proving the
mutation persisted in Google Flow.
